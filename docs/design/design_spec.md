## 1. 세계관

동네 끝 작은 온실 정원. 새싹 정령 '움'이 손님을 맞고, 내 안의 씨앗이 어떤 꽃으로 필지 함께 들여다본다.

| 요소 | 세계관 속 표현 |
|---|---|
| 나 | 내 씨앗을 처음 심어 보는 정원 친구 |
| 검사 | 60문항을 열 개의 화분에 6개씩. 화면 제목 "첫 번째 화분" … "열 번째 화분" |
| 16유형 | 16가지 꽃, 네 계절 정원 (`type_naming.md`) |
| 리포트 | 나의 꽃 도감 한 장: 꽃 · 우리 정원의 꽃말 · 거울 문장 |
| 공유 | 9:16 꽃 카드 (계절 색 바탕) |
| 상담 | 정원 친구 셋 — 지온 · 하랑 · 다온 |
| 확장 아이디어 | 상담에서 정한 작은 한 걸음을 해내면 정원에 잎이 늘어남 (Finch식, 중기 이후) |

- **서비스명**: '피어나'(가칭). 후보 마음정원 · 씨앗노트. 상표 검색 뒤 확정.
- 세계관은 **장식과 이름**에만 쓴다. 리포트·상담 본문 문구는 기존 데이터 그대로이며, 세계관 은유로 본문을 덮지 않는다(실용 가치 유지).

## 3. 색 · 글꼴 · 크기

값은 `tokens.json`이 기준이다. 요약:

- **색**: 바탕 #F3F7EF / 카드 #FFFFFF / 주 버튼 잎 #4F7A54 / 보조 바탕 새순 #E4ECDF / 본문 흙 #3E3127 / 보조 글자 #62584E / 선 #D5E2CF / 추천 칩 꽃잎 #FBE3E8 / 강조 햇살 #FFE08A
- **계절 색**: 봄 #FBE3E8 · 여름 #DDEDF4 · 가을 #F8E5CF · 겨울 #E7E5F3 (밝기 동일, 우열 없음)
- **글꼴**: 제목 고운바탕 700 · 본문 고운돋움 400 · 움의 한마디 개구 700. 일본어 짝 Zen Old Mincho / Zen Maru Gothic / Klee One
  - 고운돋움은 굵기가 하나뿐이다. 본문에서 굵게가 필요하면 고운바탕 700을 쓰거나 크기·색으로 강조한다(가짜 굵게 금지).
- **한국어 줄바꿈**: 전역 `word-break: keep-all`. (시안 HTML에는 빠져 있어 "알아봐 주 / 는"처럼 끊긴다. 구현 때 반드시 넣는다.)

## 4. 공통 규칙

- **모바일 우선**: 390 × 844 기준. 좌우 여백 20px. 데스크톱은 가운데 정렬 최대 폭 480px 정도의 모바일 레이아웃.
- **터치 영역 44px 이상**. 주 버튼 56px, 보조 버튼 50~52px, 입력창 48px.
- **대비**: 글자 4.5:1 이상. 연한 바탕(새순 #E4ECDF) 위 잎색 글자는 4.09:1이라 **짙은 잎 #3B5E3F**를 쓴다.
- **우열 없음**: 꽃·계절은 크기·밝기·순서로 차이를 두지 않는다.
- **이모지**: 리포트·화면 장식에 쓰지 않는다(다온 답변 최대 1개 규칙은 chatbot_spec 그대로). 아이콘은 선 SVG.
- **위기 안내 카드**는 계절·유형과 관계없이 한 가지 모습(흰 바탕 + 잎색 1.5px 테두리, 제목 고운바탕).
- **면책 위치**: user_flow_spec §16 #5 그대로 (대화: 헤더 아래 고정 띠 / 리포트: 최종 CTA 아래 / 랜딩·검사: 푸터).
- **하단 탭 바**: 홈 · 내 결과 · 상담. 리포트 · 상담 허브에 표시. 검사 진행 중과 대화 화면에서는 숨긴다.
