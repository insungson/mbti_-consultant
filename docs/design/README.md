## 구현할 때 주의

1. 문구는 `data/*.json`이 원본이다. 시안 속 문구와 다르면 데이터를 따른다. 시안에서 새로 쓴 문구는 `design_spec.md` §6.
2. 전역 `word-break: keep-all` (시안 HTML에는 빠져 있음).
3. 16유형 꽃 이름은 **초안**. 확정 전에는 데이터의 별칭(nickname)을 바꾸지 않는다 (`type_naming.md` §4~5).
4. 캐릭터 SVG는 스케치. 최종 일러스트가 나오면 같은 파일명으로 교체한다.
5. 진행 순서: user_flow_spec §14대로 랜딩 → 검사 → 리포트 → 상담, 한 화면씩.
